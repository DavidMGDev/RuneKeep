RuneKeep cards come in **two kinds** (owner, 2026-06-12):

1. **Immutable cards** — generated by the system / character creation. The user CANNOT modify them. Examples: class card, class-feature cards, subclass/ancestry/community/domain scans, and the new **weapon and armor cards**. All forged stat cards are immutable.
2. **Custom cards** — authored by the user, editable with the pencil control. Examples: **experiences** (the only custom cards so far). Authored via `src/components/card-editor.tsx`.

**Editing rule (important):** modifying a custom card must NOT happen in the character-sheet carousel. Editing lives only in character creation today, and in the future in a dedicated **settings panel** (not yet built). The sheet carousel is read/flip only — never put a pencil/edit affordance on a card in the sheet hand.

**How to apply:** when adding a new card type, classify it immutable vs custom. New stat cards (weapons, armor, items) are immutable. Only user-authored cards get the pencil, and only outside the sheet carousel. See [[project_runekeep_overview]] and [[runekeep_dev_pipeline]].
