RuneKeep is an animation-first **Daggerheart** TTRPG companion app at `D:\Tools\Homebrew\Daggerheart\RuneKeep`. **Expo SDK 54** + RN 0.81 + React 19 + Expo Router + New Architecture + Reanimated 4.1, TypeScript. (Pinned to SDK 54 because the owner's **Expo Go is 54.0.8**; don't bump SDK without checking their Expo Go. Downgrade procedure: `npm i expo@^54`, `npx expo install --fix`, then clean reinstall `rm -rf node_modules package-lock.json && npm install` to clear the peer conflict.) GitHub: https://github.com/DavidMGDev/RuneKeep.git (owner DavidMGDev, public).

**Fonts:** Archivo superfamily (Black = name/numerals, 400-700 = labels) — matches the owner's preferred mockup (heavy grotesque sans, NOT serif). **Accent:** an `AccentProvider` context recolors all red text + tints active heart/stress pips; a temp swatch bar (top) picks the color.

**Verify UI** by exporting web + headless Edge screenshot — the helper is `bash .rk-shot.sh <tag> <port>` (gitignored). Gotchas learned the hard way: Edge `--screenshot` needs an ABSOLUTE path (relative writes 0 bytes); first 1-2 screenshots are often blank (paint timing), retry; use **`http://127.0.0.1:<port>/` not `localhost`** — localhost can resolve to a zombie server on IPv6 and you screenshot an empty "Directory listing for /" (script already pinned); never run two headless Edge at once (shared-profile lock); `adjustsFontSizeToFit` shrinks on NATIVE but NO-OPs on react-native-web — this made every mobile label render smaller than web (pass-5 root cause); since PR#45 `SheetText` auto-shrink is **opt-in via `fit`** (only the character name uses it) — fixed labels must be sized to fit their box or they ellipsize on both; **never call a `'worklet'` function directly in React render** (e.g. in `useSharedValue(fn())`) — it crashes web SSR (blank export); **never pass a FUNCTION as a runOnJS argument** — it crosses the worklet boundary as a bare object ("x is not a function" at runtime, #92): bind JS closures per call site and let runOnJS carry primitives only. **MOBILE-FIRST per owner: never add web-only layout branches; web inherits the mobile design (the old web-only marginTop hack is gone).**

**Why:** Built from a Ligma mockup export (see [[project-ligma-overview]]); the first screen is a responsive character sheet.
