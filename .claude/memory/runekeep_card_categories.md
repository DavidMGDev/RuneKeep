The card carousel went from a 2-deck a↔b toggle to an **ordered LOOPING ring of categories** (PRD #214, v0.2, shipped 2026-06-14 across PRs #221/#223/#224/#225/#222/#226). See [[runekeep_float_menu_roadmap]], [[runekeep_card_types]], [[runekeep_modifier_system]], [[project_runekeep_overview]].

**Ring (`src/features/character-sheet/carousel-categories.ts`, pure + tested):** `CardCategory` = `abilities | inventory | notes | wildshape`. `CATEGORY_ORDER` = [abilities, inventory, wildshape, notes] (#227: Notes AFTER Beastform). `CATEGORY_LABEL.wildshape = 'Beastform'` (#227 — key stays `wildshape`). `activeRing({isDruid, hidden})` → canonical order minus `hidden[]` categories (any can be hidden via the Cards panel), Beastform only for Druids, never empty (falls back to abilities). Notes shows by DEFAULT. `nextCategory(ring, current, dir)` wraps both ways. carousel-context holds the ring + replaced `toggleCategory` with `cycleCategory(dir, arrival)`; over-scroll armed-release walks the ring in the pulled direction (first-card-right = prev/arrive-end, last-card-left = next/arrive-start — continuation lands on the opposite extreme, #188 unchanged). DeckSwitchIndicator + the float trigger glyph resolve per-category icon/label via `CategoryGlyph`/`CATEGORY_LABEL`. Context snaps `category` back to ring[0] whenever a toggle removes it (no machine-state guard — #227, the Cards panel unloads the carousel). **Switch flicker fix (#227):** a `useEffect([category,count])` in card-carousel snaps the `center` index to the landed card so its full-res mounts on frame 1 (the live tracker is grind-frozen ~1s, which had left the landed card on its LOD thumb).

**Druid Beastform (`src/lib/wildshape-data.ts`, generated from `_pdfwork/wildshape.json` via `gen_wildshape.py`):** 24 Beastforms, all 4 tiers, transcribed from the rulebook (Druid pp.31-36; tier table p.110). Each = a colored **2-face flip card** (#227, like the class-feature card): face 0 = overview (tier · stress · attack · stat deltas via `wildshapeSummary` · examples, pageMark 1/2), face 1 = features (pageMark 2/2) — normalizes title size, no tiny text. Druid-only deck (redesigned-sheet builds it only when `className==='druid'`; jobs keyed `ws-<id>-0/-1`, assembled into one CardItem id=`ws-<id>`). Enabling layers trait/Evasion/damage-threshold deltas through the existing modifier engine (effectsForCardId resolves `ws-*` ids) AND marks the form's Stress (`applyWildshapeCost`: spill to HP when Stress full, NEVER lethal at 1HP/full-Stress). **One active at a time** (onToggleCard drops any other `ws-*` on enable); dropping out reverts effects, **no Stress refund**. `toSheetCharacter` overrides the displayed name to `activeWildshapeName(file)` so you know you're transformed even browsing other categories; `file.name` unchanged; leaving the category never de-transforms. Evolved/Hybrid forms (Legendary/Mythic Beast/Hybrid) model flat bonuses + describe the player-choice remainder in text. Druids CANNOT author Wild Shape cards.

**Notes (all classes):** schema `notes?: ExperienceDef[]`. Freeform note cards, optional titles, NOT in inventory. Empty deck → one non-toggleable placeholder card. Shown by default.

**Cards panel (#227, `category-panel.tsx`):** float-menu **due-SOUTH slot is now "Cards"** (`PlaceholderKind` 'cards'; replaced the truncated "Toggle Notes") → opens an OverlayShell panel that toggles each applicable category on/off (switch per row; ≥1 always stays on — last switch locks). Persists `file.hiddenCategories?: CardCategory[]` (additive; legacy `showNotes===false` maps to notes hidden, kept read-only). Carousel UNLOADS while the panel is open (`floatKind==='level'||'cards'` guard), so disabling the current category lands the player on a valid one (via the snap-back) when it reopens.
