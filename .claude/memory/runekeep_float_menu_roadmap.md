In-play actions hub for the character sheet, all reached from the **radial float menu** that replaced the deck-toggle button. Built across PRs #162–#167 (merged through 2026-06-13). See [[runekeep_dev_pipeline]], [[project_runekeep_overview]], [[runekeep_card_types]].

**Float menu** (`src/features/character-sheet/redesign/float-menu.tsx`): trigger at design center (81,249), upper-left corner. **FPS emote/spray wheel** — contiguous angular WEDGES, selection by nearest-centre angle past a center dead-zone, NO dead gaps; left half = cancel gap. Press opens; drag→release on a wedge fires, release in dead-zone/gap cancels; plain tap pins open for direct label taps. Overlay in ONE wrapper at `zIndex 9999` so the whole sheet (icons AND cards) is under the dim, untouchable while open. **5 slots** (#174, was 6 — Switch removed) at -90/-45/0/45/90° (STEP 45, HALF 22.5): **Modifiers due-NORTH** (was Settings — replaced #175/#185; `PlaceholderKind` 'settings'→'modifiers'), then New Card · Level Up · Rest, **"Cards" due-SOUTH** (#227 — `PlaceholderKind` 'cards'; opens the category-toggle panel. Was briefly "Toggle Notes" in #214 but that label truncated). Druid Beastform was NEVER a float slot — it's a carousel category (see [[runekeep_card_categories]]). Menu closes IMMEDIATELY on select/cancel (no animated scrim) — fixed a freeze where the fading zIndex-9999 scrim stranded over the panels (#169).

**Deck switch (gear #174; reworked TIME-BASED #188/v1.1.1; N-CATEGORY RING #214/v0.2):** the over-scroll now loops through an ordered ring of categories (`cycleCategory(dir)`), not just inv↔arsenal — see [[runekeep_card_categories]]. Originally inv↔arsenal switching is a sideways over-scroll. **#188 update:** now BOTH gear (50% cap) AND normal scroll on the first/last card (15% cap) trigger it; over-scroll fades in the indicator, then a radial fills over a **1s hold** (quartic ease in+out) — release-while-full switches, scroll-back cancels (no more distance-arm). Indicator sits as a phantom card just beyond the pushed edge (carousel-aligned). Switch lands on the OPPOSITE extreme (first card → last card of new deck = continuation), ghost preloads full-res for first-seen cards. Geometry: `OVERSCROLL_CAP_GEAR/NORMAL`, `OVERSCROLL_HOLD_MS`; `ArrivalEnd` in carousel-context.

Original #174: a sideways **pull-to-refresh on the bottom golden gear** (the grind-scroll cog). Past a deck end the gear grind clamps `rotation` and shoves the whole fan sideways (~85% of screen) via a `overscrollX` whole-fan translate; an indicator (progress ring + the TARGET deck's real SVG — `ArsenalIcon`/`InventoryIcon`, now exported from `deck-toggle-icon.tsx`) emerges in the OPPOSITE gap. **Armed-release**: reach the arm point → lock; lift while armed → switch; drag back → cancel. Gear-only + expanded-only → never accidental, hand never collapses. `GEAR_SWIPE_PX` 200→120 so ONE center→edge drag covers whole deck + the commit (any card, either dir, ~5% case margin). New switch transition: incoming deck preloads off-screen as a **ghost fan** (`GhostFan`/`GhostSlot` in card-carousel), old hand slides DOWN + fades at bottom while ghost rises+fades in centered, seamless commit (ghost lingers 120ms so cache-warm live deck paints under it). Also: carousel loads CENTERED on create+load (recenter-while-compact effect in `carousel-context`), not first card. Tunables in `carousel-geometry.ts`: `OVERSCROLL_GAIN/ARM/MAX`, `GEAR_SWIPE_PX`, `DECK_EXIT_DROP/DECK_ENTER_RISE`. **Device-verify pending.**

**Interfaces (all shipped, reached via `floatKind` switch in redesigned-sheet):**
- **New Card** (#164, `new-card-flow.tsx`): card editor + target picker → inventory / arsenal / both. Persists to `file.customCards`; forged + routed into the deck(s) live.
- **Rest** (#165, `rest-panel.tsx` + pure `lib/rest.ts`): short/long rest, choose up to 2 moves (same twice OK; 1 allowed; "Rest again"). Effects on live tracks. Faithful to `assets/temp/Rest/Rest.png`.
- **Settings** (#166) — **REMOVED #175/#185.** `settings-panel.tsx` + `number-keypad.tsx` DELETED; replaced by the read-only **Modifiers** panel (`modifiers-panel.tsx`). No more manual derived-stat editing — cards drive every number now (see [[runekeep_modifier_system]]). `DomainCardInfo` type moved to `domain-card-info.ts`. Level editing now only via Level Up; the Vault (≤5 active domain) logic in `toSheetCharacter`/level-up still exists but its editor is gone.
- **Level Up** (#167; REBUILT #203/v1.1.2): now FULL-SCREEN around `StraightCarousel` (the creation carousel) — the New Domain Card picker is the ONE carousel, fullscreen-able, no name labels; "Choose this card" selects the centered card; the extra-domain advancement raises the pick count to 2 on the SAME carousel. `domain-carousel.tsx` DELETED. Tier Experience uses the experience editor. **Sheet `CardCarousel` is UNLOADED while level-up is open** (`floatKind==='level'` guard in redesigned-sheet) for perf. Pure `lib/leveling.ts` unchanged. Experiences (#202): `ForgedCard experience` mode = long auto-fit title (≤7 lines) + visible +N bonus, no description; `CardEditor experienceMode`. All float panels + the wheel now animate in (#201, OverlayShell/CardEditor/float-menu fade+rise). Original #167: auto per-level (+1 level, +1/+1 thresholds, a domain card; tier-start 2/5/8 → +2 Experience, +1 Prof via proficiencyForLevel, clear trait marks at 5/8) + choose-2 advancements with slot limits + sub-pickers. Faithful to `assets/temp/Level/`.

**State model:** `RedesignedSheet` now holds the CharacterFile in state (`file`/`mutateFile`) so sheet edits re-derive the decks live. Runtime `character` (resources) stays separate; settings/level edits update both. `toSheetCharacter` layers all overrides + modifiers onto class/creation defaults.

**Schema (character-file.ts): all additive, `schemaVersion` STAYS 1** (don't bump — existing saved characters must keep loading): `customCards`, `maxHp`, `stressMax`, `armorScoreMax`, `evasionBase`, `proficiencyBonus`, `traitBonuses`, `modifiers` (+`StatModifier`/`modSum`), `activeDomainCardIds`, `thresholdBonus`, `advancementMarks`, `traitMarks`, `subclassTier`, `multiclassName`; `ExperienceDef.modifier`.

**Pure + tested:** `lib/rest.ts`, `lib/leveling.ts`, `modSum` (jest 82 total). Rules transcribed from gitignored `assets/temp/Rest/` + `assets/temp/Level/` (copyrighted — never bundle/push; crop+upscale with PIL to read).
