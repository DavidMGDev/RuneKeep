A four-phase maintainability refactor landed as **stacked PRs #301→#302→#303→#304** off PRD **#300** (2026-06-16). **It moved a lot of files — older memories (esp. [[project-runekeep-overview]]) cite pre-refactor paths; trust THIS for current structure and verify before using an old path.**

**Path moves (old → new):**
- Static game data → **`src/data/`**: `features/cards/catalog` + `catalog-effects` + `ancestry-traits` + `ancestry-trait-regions`, `features/create/equipment-data` + `class-data` + `class-inventory-data` + `item-colors`, `lib/loot-data` + `lib/wildshape-data` (+ its test). All imported as `@/data/...`. Accessors (`cardById`, `weaponById`, `lootById`, `wildshapeById`, …) live with the data. `catalog.ts` still generated by `scripts/generate_card_catalog.py` (now writes to `src/data/`); equipment/loot/wildshape come from the **local-only** `_pdfwork/codegen.py` (not in repo — point its output at `src/data/`). Integrity guarded by `src/data/data-integrity.test.ts`.
- **`character-sheet/redesign/` → `character-sheet/sheet/`** (it's the live sheet UI, not an experiment). So `redesign/redesigned-sheet.tsx` is now `sheet/redesigned-sheet.tsx`.
- `src/components/` is now a **shared kit ONLY** (2+ feature use). Single-use moved into features: `accent`→`character-sheet/components/`, `rune-chip`→`gallery/components/`, `card-divider`+`chamfered-image`→`create/components/`. The create feature's UI also lives in `create/components/`.
- `create-screen.tsx` split (1208→645) into siblings: `create-types`, `create-constants`, `create-loaders`, `create-rail`, `create-ui`, `deck-glyph`, `traits-tab`, `experiences-tab`.
- `redesigned-sheet.tsx` pure helpers → `sheet/sheet-utils.ts` (tested in `sheet-utils.test.ts`).

**Deleted:** `design-reference/` (UI is built; the Ligma oracle is gone — old "design-reference workflow" steps no longer apply), the stale `docs/` files (ADR 0001, animation-stack, card-carousel-architecture, ui-fix-brief, the v02 PRD) — **consolidated into `docs/architecture.md`** (DesignStage responsive strategy + card-carousel design + on-device perf rules). `assets/temp/` removed from git (now fully gitignored; the licensed rulebook stays local-only).

**Conventions established:** every feature has a `SPEC.md` (responsibility, key files, public surface, data deps) = the AI code map. No DB / no network (deliberate). Line guideline: code files <~150 lines, but pure **data/style/test files are exempt** and cohesive animation-coupled components (redesigned-sheet orchestrator, card-carousel, carousel-context, the resource tracks) are **deliberate ponytail-commented exceptions** — splitting them risks animation regressions needing on-device verification.

**Build front-door:** `npm run build:apk` (wraps `apk-build/build-apk.ps1`, now portable via `$PSScriptRoot` + a single `$ver`), plus `npm run prebuild:android` and `npm run typecheck`. See [[runekeep_apk_build]].

**Verification used:** `npx tsc --noEmit` + `npx jest` (208 tests) green after every phase; asset `require()` paths verified to resolve on disk (tsc can't see ambient `*.svg`/`require` imports). On-device smoke still owed for the create flow + sheet (per [[runekeep-verify-animations-manually]]).
