# src/data — static game data

**Responsibility:** the single home for all static Daggerheart rulebook data, with thin typed
accessors. Bundled with the app — no database, no network, fully offline. Pure data files are
allowed to be long; they are *data, not logic*.

## Files
| File | Holds | Accessor(s) |
|------|-------|-------------|
| `catalog.ts` | every playable card (domain/ancestry/community/subclass) + two-LOD art `require()`s | `cardById(id)` |
| `catalog-effects.ts` | catalog card id → permanent stat effects | `CATALOG_EFFECTS` |
| `equipment-data.ts` | all weapons + armor (every tier) | `weaponById`, `armorById`, `PRIMARY_WEAPONS`, `TIER1_ARMOR`, … |
| `loot-data.ts` | loot + consumables | `lootById`, `ALL_LOOT` |
| `wildshape-data.ts` | Druid Beastform forms (tiers 1–4) + the cost logic | `wildshapeById`, `applyWildshapeCost`, … |
| `class-data.ts` | per-class starting stats + feature text | `CLASS_DATA`, `featurePages` |
| `class-inventory-data.ts` | per-class starting inventory options | `CLASS_INVENTORY`, `itemTitle`, `itemOptionId` |
| `item-colors.ts` | inventory item colour palette | `itemColor` |
| `ancestry-traits.ts` | mixed-ancestry trait mapping + helpers | `ANCESTRY_EFFECT_TRAIT`, `mixedActiveTrait`, … |
| `ancestry-trait-regions.ts` | cross-out text regions for mixed ancestry | `strikeLines` |

## Public surface
Consumers import accessors by id (`cardById`, `weaponById`, …) — never index the raw arrays. The
effect/modifier engine (`src/features/cards/card-effects.ts`) resolves any card id to its effects
through this layer.

## Generation
`catalog.ts` is generated by `scripts/generate_card_catalog.py` (Metro needs literal `require()`
paths, so the catalog can't be globbed at runtime). `equipment-data`, `loot-data`, `wildshape-data`
are generated by a **local-only** `_pdfwork/codegen.py` (not in this repo) — point its output at
`src/data/` when regenerating.

## Tests
`data-integrity.test.ts` guards id uniqueness, accessor round-trips, the `CATALOG_EFFECTS → catalog`
cross-reference, and tier-1 starter invariants. `wildshape-data.test.ts` covers the beastform logic.

## Why typed `.ts`, not JSON
`catalog.ts` holds ~270 Metro `require()` image handles JSON can't represent, and the data is
generated. The win is *one home + separation from logic*, not a format change.
