RuneKeep v0.27.1 - tap outside the wheel to close it, a smoother creator, and a way to see what the sound is doing.

- THE FLOAT MENU CLOSES AGAIN in the browser. Tapping outside the wheel did nothing at all, so the only way out was to pick something. The tap was landing, working out where it landed threw, and the whole press was lost in silence. It cancels now, the way it always did on a phone.
- CHARACTER CREATION IS SMOOTHER. Changing section built every card in the new deck at once, and a deck can be eighty cards, each one an animated card with its own gestures. Only the ones near what you are looking at are built now, which is all the screen was showing you anyway.
- BUTTON PRESSES STOPPED STUTTERING. A sound that fails to load was being retried on every single press, forever, with a file lookup each time. It is tried once now.
- SOUND, A SECOND ROUTE. Loading a sound has two paths and which one works depends on how the app was built. It tries both now, so a wrong guess about which one applies is no longer the difference between audio and silence.
- SOUND, A WAY TO SEE. Hold the speaker on the main menu and the app tells you what its audio is actually doing: running or not, how many sounds are loaded, how many failed, and whether it is muted. A broken app used to look exactly like a quiet one.
- WHEN SOUND IS OFF, IT SAYS SO. The speaker reads "Sound off" instead of relying on a small crossed-out icon.

If Android sound is still missing, hold that speaker. The line it shows names the cause.

Sideload: enable Install unknown apps, then open the APK.
