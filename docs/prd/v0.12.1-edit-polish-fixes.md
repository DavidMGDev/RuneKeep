# v0.12.1 — Edit Mode polish + fixes

Eight of the ten bonus items from the owner's list. Items 1 (expansion cards in the archive) and 2
(NFC-share any card + sheet receive) are deferred into the v0.12.2 "The Void" content phase — they're
expansion/library-card features that pair naturally with bringing the Void content into the app, and
sharing *system* cards needs a catalog-reference design that belongs with that work.

## Shipped (edit mode + radial + NFC wording)
3. **Swipe hint above the card** — the three upward chevrons on selected cards moved from inside the card
   to just above it.
4. **Raise 2.5×** — selected cards lift `EDIT_RAISE` 5 → 12.5 px.
5. **Grab animates both ways** — the pile now RISES from the card's row slot up to the finger via a timed
   `grabAnim` envelope (symmetric with the commit spread), instead of snapping to the finger.
6. **No commit flicker** — re-introduced the no-blink bridge: the drag state is held until the reordered
   deck is live (a deck-change effect flips it), with the new-order ranks pre-written so the bridge frame
   is already correct. A 500 ms safety timeout preserves the v0.11.2 "never wedge" guarantee.
7. **Delete-all-on-screen scrolls to remaining** — when the deck shrinks past the current view, the row
   springs back to the last remaining card instead of sitting empty.
8. **Deleted cards deselect** — a selected card that leaves the deck is pruned from the selection, so the
   "X/Y Cards" count never counts ghosts (context-level prune on deck change).
9. **Radial icons legible** — the delete (trash) + favorite/unfavorite (star ± crossout) glyphs use
   thinner strokes and wider spacing.
10. **Radial pop-ups fade in** — the Move / Delete sheets `FadeIn` instead of popping.
- **NFC wording** — dropped the confusing "Send screen / Receive screen" phrasing from the send+receive
  modals.

## Deferred to v0.12.2 (with "The Void")
1. Card archive shows homebrew/official/custom **expansion** content (needs a library-card renderer in the
   gallery — pairs with rendering the Void cards).
2. Hold a full-screen archive card → **NFC-share any card** + receive into the current category with an
   animation (blocked on: system cards are images, not text, so sharing them needs a catalog-reference
   payload; and there's no sheet-side receive yet — both belong with the Void sharing work).
