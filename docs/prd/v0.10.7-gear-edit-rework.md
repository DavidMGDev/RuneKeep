# v0.10.7 — Golden Gear Edit rework + Favorites rework

A full rework of the card-management interface (the Golden Gear Edit mode reached by holding the
carousel gear still) plus a rework of Favorites. Owner-driven; motion is device-verified.

## Golden Gear Edit

### Feel / interaction
- **Exit by tapping the gear once.** In edit mode a still tap on the gear pad calls `exitEdit`
  (`card-carousel.tsx` onEnd/onFinalize, guarded by a new `editPadTouch`). Gear **scrolling is disabled**
  in edit mode (the edit branch never runs the grind path). The `Done` button is gone.
- **No tap-off close.** `ExpandVeil` still blocks sheet taps while editing but its `onPress` is a no-op
  when `editing` (owner found tap-off too twitchy). Only the gear tap exits.
- **Momentum scroll.** The flat-row scroll now carries release velocity into the snap spring
  (`editPanR = EDIT_GAP/ANGLE_STEP`) and rubber-bands at the ends (`OVERSCROLL_RESIST`) — matches the
  normal carousel instead of the old dead snap.

### Multi-select is first-class
- **Pile drag.** Up-swipe a selected card and the whole selection drags together as a pile: leftmost
  card on top at the finger, each next `+3px` right / `+2px` down; the rest reflow to close the gap and
  open a landing gap (a placement preview). Dropping commits the reorder. The pure move maths is
  `reorderBlock` (`edit-drag.ts`, unit-tested); the on-screen pile is its preview. Grabbing an
  UNselected card still drags it solo. A subtle iOS-style `shake` wobble plays while dragging.
- Per-index `raiseOrderSV` / `raisedBeforeSV` / `raiseCountSV` shared arrays (recomputed from
  `raisedIds`) drive the reflow in the slot worklet.

### Flavor
- **Deeper dim:** the edit backdrop darkens ~12% more (`ExpandVeil` opacity `0.62 → ~0.74` via `editMode`).
- **Breathing selection:** raised cards pulse a synced white overlay `0 → 20%` (a plain View, cheap
  under the dim). A card that JOINS the selection fades in via its own `raiseSV` envelope, so it never
  snaps to the shared breath's current peak. The loop runs while anything is selected.

### Actions = a card-hold radial (replaces the ever-present bar)
- Hold a selected card still (~300 ms) → a **full-circle spray wheel** blooms around it
  (`CardRadialMenu` + `pickWedgeFull`/`clampMenuAnchor` in `carousel-geometry.ts`), the float menu's
  cousin: options all the way around, compact, kept inside the screen edges. Drag toward an option and
  release to fire; release in the middle to cancel; a still hold that never drags just closes. The held
  card gives a small scale bounce + haptic as it opens.
- Options: **Duplicate · Favorite · Move · Delete · Send NFC** (NFC only on Android/APK). No Cards-panel
  button. Move/Delete open their confirm sheets; the rest fire on the whole selection. The trigger lives
  in the carousel pan (state `editDecided === 3`), so it never fights the pile-drag (up-swipe wins first).
- `EditControls` (the old top bar) is deleted; `card-menu.ts` is the single source of truth for the
  option list, shared by the wheel and the dispatcher (`onCardAction` in `redesigned-sheet.tsx`).

### NFC — single AND multiple
- `onSendNfc` now sends one card (a `card` payload, image inlined best-effort) OR several (an ephemeral
  one-off `Expansion`, `{kind:'expansion'}` — the envelope already supports it). `cardToLibraryCard`
  (`card-effects.ts`) is the shared converter: homebrew cards travel whole; authored keep title/body/
  art/effects; catalog → generic + resolved effects. `inlineCardImage` (`nfc.ts`) base64-inlines a
  local image when it fits the ~60 KB NFC ceiling, else drops it so the payload stays valid. The Library
  receiver accepts multi-card taps again (dumps them into "Received cards").

## Favorites rework
- **Hidden mirror.** Favorites is no longer a ring category — `availableCategories` never lists it, so it
  can't be reached by left/right transitions or shown in the category menu. It stays a real deck of
  copies, reachable ONLY via the star.
- **Sync is automatic** (unchanged, ref-keyed): a favorite copy shares its source's enable state,
  effects, tokens and dice by `ref`, so toggling either one flips both and the benefit applies once.
- **Star button is a toggle.** It opens Favorites (remembering the origin as a detour) and, pressed
  again while showing, returns to the origin — as does an over-scroll either way. It renders **toggled
  (lit)** while Favorites is up (`OctaBadge active`).
- **No adds in the mirror.** Add Card / Add Gear toast **"Can't add cards to favorites"** while Favorites
  is the live category (`RedesignedBody` guard). The card-hold radial there offers only **Unfavorite**
  (Duplicate/Move/Delete would touch the original) → `removeFavoriteCopies`.
