# v0.12.0 — Golden gear device fix + expansion toggles + "The Void" groundwork

This release ships the two bounded, high-value pieces of a large three-part request, and lays the
groundwork (all data extracted + a decisions doc) for the big one. The full "The Void" content
integration and per-character expansions are the next phase, gated on owner decisions.

## Shipped

### 1. Golden gear device-compatibility fix
The bottom-of-sheet golden gear (scroll / enter-edit / tap-to-return) was **completely non-functional on
some Android devices** (Motorola G-series, several Xiaomi) while working on Samsung A54. Root cause: the
gear's touch pad is a transparent, layout-only `View`; under the New-Architecture (Fabric) renderer some
OEM ROMs flatten/collapse such views, so the master pan never received touches there. Fix:
`collapsable={false}` + a hairline background force a real, hit-testable drawing layer, and the pad is
slightly wider/taller and lifted off the extreme bottom edge (clear of the Android gesture-navigation home
strip). Owner-verified on-device on an affected phone; fallback if still failing is a native
`setSystemGestureExclusionRects` config plugin.

### 2. Expansion enable/disable toggle from the hub
Each expansion row in the Card Library now carries an enable/disable **toggle on the right** (disabled rows
dim); the in-detail enable/disable button is removed. No more opening an expansion to turn it on/off.

## Groundwork (not shipped as features; local only)
- **All of "The Void" extracted** (8 PDFs → `assets/temp/void-data/*.md`): 6 classes, 6 ancestries, 6
  communities, 6 transformations, 2 new shared domains (Blood ×21, Dread ×21). Verified via image-render +
  zoomed crops.
- **Decisions doc** at `assets/temp/THE-VOID-integration-plan.md`: the phased integration plan, the
  per-character-expansions design, and Q1–Q6 for the owner (placeholder art, playable-scope, mechanics
  fidelity, etc.). The full integration is blocked on these answers + the previously-deferred
  "custom standalone classes" work.

## Out of scope (next phase)
- The Void as a bundled official expansion with real cards; Void classes playable in creation/level-up;
  the bespoke class mechanics (Favor, Combo Die, tokens, Crimson Rite, summons, transformations); cut LOD
  card art + Recraft-processed banners (blocked on final art); per-character expansion selection.
