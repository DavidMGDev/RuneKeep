# v0.11.1 — Golden Gear Edit: desaturate + drag rebuild

Third pass on Golden Gear Edit (after v0.11.0), from on-device testing. Nine changes: a desaturation
theme for the whole edit chrome, a grind-size straight row, and a full rebuild of the drag-to-rearrange
and the action wheel. Motion is owner-verified on device; the pure maths (reorder, menu options) is
unit-tested.

## 1 — Row = gear-scroll size, straightened
The edit row now matches the golden-gear-scroll (grind) size AND height exactly: `EDIT_SCALE 0.35→0.45`,
`EDIT_ROW_Y 505→631` (the grind centre Y), `EDIT_GAP → 106` (grind card ≈103px + a 3px gap). No curve,
no fan tilt — a dead-straight row.

## 2 — Desaturation theme + gear press-flash
The separate arming ring is gone. Instead the gear itself gives feedback: `gearFlash` fades the gears to
masked white on press; on a hold-to-enter it melts into `desat` (0→1). In edit mode the whole chrome —
the screen border and both gears — crossfades to **grayscale twins** (new `*-gray.webp` assets, ffmpeg
luminance), and the edit UI (banner, radial) uses a light-gray palette. `enterEdit`/`exitEdit` drive
`desat`/`gearFlash`; exiting flashes the gears white then back to gold. All remnants clear on exit.

## 3 — Centered desaturated banner
`EditHud` moved to mid-screen (the row is low now) with a full-bleed **banner** — desaturated blue fill,
top+bottom rules only (side edges under the border) — holding "Edit Mode" + the live "X / Y Cards" count,
Deselect All below.

## 4 — Breath 80% faster
940 → 522ms.

## 5 — Drag rebuild (ghost + staged, no blink)
- The pile **eases** toward the finger (frame-callback exponential smoothing), not a snap.
- A single breathing **ghost card** (white outline) marks the insertion slot, so the row only ever opens
  ONE slot of preview — even dragging a whole stack (no more pushing the right side off-screen).
- On release: the gap **widens** 1→N (`gapWidth`), THEN the pile **spreads** into it (`dropSpread`), THEN
  the reorder commits. `editGrabbed` flips off only once the reordered deck lands (a deck-change effect +
  pre-written ranks), so there's no 1-frame blink to the old positions.
- Edge autoscroll ramps ~30% harder over the outer 30% of the screen.
- All drags go through the group path (grabbing an unselected card selects it) — the clean, blink-free path.

## 6 — Radial back to spray-select
The wheel works like the sheet float menu again: hold → bloom → drag to a wedge → release to fire (the
carousel pan drives the finger + highlight via `pickWedgeFull`). Full circle, icon-only, bigger icons,
desaturated. Unfavorite is a **diagonal-crossout** star; NFC reuses the send-panel broadcast glyph.

## 7 — Exit: tap vs hold
Tap the gear → close the hand to **compact**. Hold the gear → drop back to the **expanded** arc. Both run
the reverse desaturation.

## 8 — Badge frames
`OctaBadge` uses a `ChamferBox` (chamfered rectangle, thin outline) whose fill IS the button, so the
Favorites toggled-on state fills the whole shape. `AddCardGlyph` is wider and drops the folded corner.

## 9 — Scroll then hold no longer enters
Once a gear gesture has scrolled ≥ `EDIT_SCROLL_CANCEL` (1.5) cards, a still hold no longer enters edit,
and the press-white fades back to gold.

## Fix
Releasing right after the enter-dwell (before `editMode` animates past 0.5) no longer collapses the hand
to compact (`enteringEdit` guard).
